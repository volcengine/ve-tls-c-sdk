# C SDK 设计说明

## 背景与目标
面向多端与 IoT 的 TLS Producer 需要可复用的 C Core，保证性能、资源占用与行为一致性，并支持平台适配与能力裁剪。

## 架构分层
### Core
- 发送队列、批量聚合、压缩、重试与回调
- 持久化队列与断点续传语义
- 错误码、统计指标与统一配置

### Adapters
- 文件系统、时间、线程、网络与加密适配
- 以函数指针形式注入，便于替换

### Bindings
- JNI/FFI 绑定层，保持稳定 ABI
- 不包含核心业务逻辑

## 分支策略
- master 为能力基线
- live 与 master 功能等价，仅扩展平台编译支持
- bricks 仅保留最小发送链路与必要配置
- persistent 在 master 基础上增加落盘队列与断点续传，限制单线程发送

## 设计原则
- 行为一致性优先，分支差异最小化
- 低依赖、低资源占用、可裁剪
- 配置稳定、兼容升级、避免破坏性变更
